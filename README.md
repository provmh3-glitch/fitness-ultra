# ⚡ Fitness Ultra

Ultra-fast fitness tracking with Apple Watch integration and real-time weather updates.

## 🎯 Features

- 🏃 **Apple Watch Integration** - Sync fitness data (steps, calories, heart rate)
- 🌤️ **Weather Search** - Get real-time weather for any city
- 📊 **Analytics Dashboard** - Track your fitness progress
- ⚡ **Ultra-fast Performance** - Built with Next.js 14
- 🎨 **Beautiful UI** - Clean and responsive design

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/provmh3-glitch/fitness-ultra.git
cd fitness-ultra

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## 🌐 Pages

- **Home** (`/`) - Landing page with features overview
- **Fitness** (`/fitness`) - Apple Watch dashboard
- **Weather** (`/weather`) - Weather search page

## 🔌 API Routes

- `GET /api/fitness/apple-watch` - Get Apple Watch data
- `GET /api/weather?city=London` - Get weather for a city

## 📦 Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type-safe development
- **React 18** - UI library
- **CSS-in-JS** - Inline styles

## 🎨 Design

Clean, modern UI with:
